# flask-backend-journey

Flask Backend Development Journey

About This Repository

This repository documents my journey from Flask fundamentals to practical backend development. It contains structured learning phases, coding exercises, mini-projects, and portfolio projects designed to strengthen my backend engineering skills.

Learning Roadmap

1. Flask Fundamentals — Routes, templates, requests, and responses.
2. Forms and Validation — GET/POST methods and input validation.
3. Database Integration — SQL, CRUD operations, and relationships.
4. Authentication — Registration, login, sessions, and password security.
5. Student Management System — Student record management.
6. Inventory Management System — Product and stock management.
7. Employee Management System — Employee and department records.
8. Email OTP Verification — Email integration and verification workflows.
9. E-commerce Application — Products, shopping cart, and order management.
10. Deployment and Portfolio — Deployment, documentation, and project improvement.

Technologies
